<h1 align="center">homebrew-tap</h1>

<p align="center">

</p>

## Usage

```bash
brew tap mavogel/tap
brew install <formula>
```

Or install directly without tapping first:

```bash
brew install mavogel/tap/<formula>
```

## About

This repository hosts Homebrew formulae and casks for my own tools, so they can be installed and updated with `brew` like any other package.
